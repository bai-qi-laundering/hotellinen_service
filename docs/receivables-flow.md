# 貨款與送件防漏
財務、物流、盤點、簽名、結帳公式均不修改。金額直接取對帳單快照，不自行重算。

- 原「核對帳單」「確認送出」保留，寄出後才登記。
- 貨款直接讀同一案件的最後已寄版本。新版本未寄時顯示待重寄，登記重寄後更新同筆金額，保留舊版；新版須重新確認飯店通知。
- 手開與已在外部平台開立的電子發票均可登記。汎宇 API 尚未串接，不自動開立。手開參考圖直接使用快照的未稅金額、稅額與總額。
- 發票登記交易核對最新版本、寄送及飯店確認，禁止覆寫既有發票。原開票後變更保護保持有效。
- 防漏名單為本期 logistics_records 客戶（沿用財務父飯店分組，鼎王依部門）、finance_settlement_groups.groups 和當月案件客戶聯集。設定名單若無本期物流與案件，明示待確認，避免別名造成假漏件。25 日／月底及設定覆寫照現有規則核對。未設定組別明示待確認。
- 雲端讀取失敗或補送未完成，不判定全部完成。寫入失敗保留表單供重試，不離線假裝完成。
- 底部三分頁：原財務、原送件中心（加防漏）、貨款登記。貨款可搜尋飯店及月份。
