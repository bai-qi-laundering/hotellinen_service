# 貨款登記
財務、物流、盤點、簽名、結帳公式均不修改。金額直接取對帳單快照，不自行重算。

- 原「核對帳單」「確認送出」保留，寄出後才登記。
- 貨款直接讀同一案件的最後已寄版本。新版本未寄時顯示待重寄，登記重寄後更新同筆金額，保留舊版；新版須重新確認飯店通知。
- 手開與已在外部平台開立的電子發票均可登記。汎宇 API 尚未串接，不自動開立。手開參考圖直接使用快照的未稅金額、稅額與總額。
- 發票登記交易核對最新版本、寄送及飯店確認，禁止覆寫既有發票。原開票後變更保護保持有效。
- 送件中心不再做「本月防漏偵測」，也不再為了對名單去掃整段出貨紀錄。未送與未開發票改看送件中心上方的本期看板。
- 雲端讀取失敗或補送未完成，不判定開票完成。寫入失敗保留表單供重試，不離線假裝完成。
- 底部三分頁：結帳戰情系統、對帳單送件中心、貨款登記。貨款可搜尋飯店及月份。

驗證：node --test statement-case.test.js tests/finance-dispatch-flow.test.js tests/receivables.test.js
部署與測試不代表已在正式資料執行開票；不以測試資料新增正式帳單或發票。
