# 特處排序、簽名儲存與退回

- 摺疊及辦公室清單使用 `inventory_config/master_template` 的飯店順序與既有 `inventoryCatalog` 品項順序。收件日期仍由新到舊，未列在範本的資料保留在後方，不會遺漏。
- 已簽名、尚未送出的品項可選原因與數量「退回重工，暫不出貨」。整筆退回會清除目前簽名／出貨欄位，原簽名仍保留在歷程；部分退回只將該數量移至重工。辦公室待出貨單不再包含重工數量。已送出的單據維持鎖定。
- 摺疊與重工的小型簽名直接隨單據保存，省去先上傳Storage及取得下載網址的兩段等待。沿用系統原已支援的inline圖片格式；辦公室簽名仍沿用Storage。
- 寫入期間顯示儲存狀態並鎖住按鈕、數量、原因及切換；成功後留在原單據確認，按「完成，返回清單」才離開，另有700ms防連點。失敗保留原目標與簽名供重試。
- 特處與辦公室送出改以Firestore交易檢查資料是否已被其他人更新，再原子寫入。遇到其他裝置先簽名／重工／送出時會拒絕覆寫，避免舊畫面把已送出單據改回或產生部分拆單。
